# /secnews [기간] [new]

국내·해외 보안 뉴스를 수집해 카테고리별로 정리하고 한국어 다이제스트(md)를 만듭니다.

## 인자 파싱 규칙

`$ARGUMENTS`를 공백으로 나눠 다음 규칙으로 해석한다:
- `24h`, `3d`, `1w` 같은 기간 → `--since` (기본값 `24h`)
- `YYYY-MM-DD` → `--date` (저장 파일명, 기본값 오늘)
- `new` → 전날 이전에 이미 수집된 기사(`"new": false`)는 빼고 정리. 같은 날 여러 번 돌려도 오늘 처음 본 기사는 `new` 로 남는다.

예시:
- `/secnews` → 최근 24시간
- `/secnews 3d` → 최근 3일
- `/secnews 1w new` → 최근 1주 중 처음 보는 기사만

## 실행 순서

1. `$ARGUMENTS`를 파싱한다.
2. 프로젝트 루트에서 수집기를 실행한다.
   ```bash
   python -m pipeline.collect_news --since 24h
   ```
3. 출력된 저장 경로의 `output/news/YYYY-MM-DD.json`을 읽는다. 소스가 실패했으면(`sources[].error`) md 맨 아래 "수집 상태"에 적는다.
4. 아래 **선정 규칙**에 따라 주요 소식 20개를 고르고 나머지는 목록으로 둔다.
5. `output/news/YYYY-MM-DD-digest.md`로 저장한다 (아래 **출력 형식**).
6. 터미널에는 카테고리별 건수와 상위 5개 제목만 짧게 출력하고 md 경로를 알려준다.

## 선정 규칙

목적은 **소식을 아는 것**이다. CVE 언급 여부로 순위를 매기지 않는다.

1. **보안과 무관한 기사 제외**: 데이터넷처럼 IT 전반을 다루는 소스에서 보안과 관계없는 기사(일반 클라우드·AI 사업 소식 등)는 뺀다.
2. **같은 사건 합치기**: 수집기는 같은 언어 안에서 제목 유사도와 공유 고유명사로 묶어 둔다(`also`, `coverage`). 한국어 기사와 영어 기사가 같은 사건이면 하나로 합치고 출처를 모두 적는다. 합친 뒤의 매체 수를 화제성으로 쓴다. 같은 매체의 연속 보도(예: 한 침해사고의 피해 기업별 기사)가 묶여 있으면 한 항목으로 쓰고 피해 기관을 나열한다.
3. **카테고리 분류** (하나만 고른다):
   - 침해사고·유출 — 해킹 피해, 개인정보 유출, 서비스 침해
   - 위협 동향 — 랜섬웨어 조직, APT, 피싱·악성코드 캠페인, 공격 기법
   - 취약점·패치 — 제로데이, 긴급 패치, 보안 업데이트 권고
   - 솔루션·제품 — 신규 보안 제품·기능 출시, 오픈소스 도구, 기술 소개
   - 정책·업계 — 규제, 가이드라인, 수사·판결, 인수합병, 투자, 인사
4. **기관 공지 묶기**: KISA 보호나라·CISA 의 "○○ 제품 보안 업데이트 권고" 같은 공지는 한 항목으로 묶는다 (예: "KISA 보안 업데이트 권고 4건: Sophos, Atlassian, Oracle, 다우기술"). 20개 자리를 공지가 차지하지 않게 한다.
5. **순위**: 화제성(합친 뒤 매체 수) → 최신순.
6. **균형**: 기사가 있는 카테고리는 최소 2개씩 넣는다. 국내 소식이 있으면 20개 중 최소 6개는 국내 소식으로 채운다. 조건 때문에 순위가 밀린 기사보다 앞에 넣어도 된다.
7. 기사가 20개보다 적으면 있는 만큼만 넣는다.

## 요약 규칙

- JSON 의 `title`, `summary` 만 근거로 쓴다. 기사 본문을 따로 가져오지 않고, 없는 사실(피해 규모, 공격자 이름 등)을 지어내지 않는다.
- 요약은 한국어 2~3문장. 원문 문장을 그대로 옮기지 말고 새로 쓴다.
- 영어 기사는 제목을 번역하고 원제를 함께 적는다.
- `summary` 가 비어 있으면 "요약 정보 없음 — 원문 참고"라고 쓴다.
- 기사에 CVE ID 가 있으면 태그로만 단다.

## 출력 형식

```markdown
# 보안 뉴스 다이제스트 — YYYY-MM-DD

> 최근 N시간 · 수집 {fetched}건 → 기간 내 {in_window}건 → 정리 {최종 건수}건 (국내 X / 해외 Y)

## 주요 소식 20

### 침해사고·유출

#### 1. 번역(또는 한국어) 제목
원제: Original English Title   ← 영어 기사일 때만
요약 2~3문장.
- 출처: [매체명](url) · [매체명](url) · YYYY-MM-DD
- 태그: `CVE-2026-12345`   ← 있을 때만

### 위협 동향
...

## 나머지 소식

| 분류 | 제목 | 출처 |
|---|---|---|
| 침해 | 제목 | [매체](url) |

## 수집 상태
- 실패한 소스: 없음 (또는 소스명 - 오류)
```

번호는 카테고리를 넘어 1~20 으로 이어 붙인다.
